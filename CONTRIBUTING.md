# Правила работы с репозиторием

- Опечатки и небольшие уточнения документации допустимы напрямую в `main`.
- Изменения Liquid, Python-сборки, даты, формулы ротации, ресурсов и лицензирования выполняются в `codex/<краткое-имя>` через pull request.
- Один PR решает одну задачу и отдельно описывает поведение, визуальную проверку и ограничения реального устройства.
- Перед merge выполнить `python build.py` и убедиться, что `git diff --exit-code -- full.liquid assets/gta-vi-logo-mono.svg` не показывает незакоммиченных generated-файлов.
- Изменения композиции и дизеринга проверяются локально и на TRMNL; локальный preview нельзя выдавать за физический 1-bit результат.
- Сторонние изображения, логотип и шрифты должны иметь источник и условия использования в `ASSET_LICENSES.md`.
- Тег `vX.Y.Z` и GitHub Release создаются после успешного CI на `main`; release notes описывают пользовательские изменения и известные ограничения.
