# Работа с GTA VI Countdown

- Перед изменениями прочитать `CONTRIBUTING.md`, `README.md` и `docs/implementation.md`.
- Для Liquid, Python-сборки, даты, ротации и ресурсов использовать ветку и pull request.
- После изменения выполнять `python build.py` и коммитить актуальные `full.liquid` и `assets/gta-vi-logo-mono.svg`.
- Не считать локальный preview проверкой серверного дизеринга или физического 1-bit экрана.
- Для каждого стороннего ресурса сохранять источник и условия в `ASSET_LICENSES.md`.
