# GTA VI Countdown — компактная версия

## Установка

1. Strategy: Static. В Static Data вставьте содержимое `static-data.json`:

```json
{"artworks":["https://raw.githubusercontent.com/lerston/trmnl-gta-countdown/main/assets/art-01.png"]}
```

Арт и шрифт размещены в этом публичном репозитории. Для нескольких артов загрузите новые PNG в `assets` и добавьте их прямые ссылки в массив через запятую. GitHub Pages и собственный сервер не нужны.

2. Remove bleed margin: Yes. Dark Mode: No.
3. Edit Markup → Full: полностью замените старый код содержимым full.liquid. Сохраните.
4. Проверьте предпросмотр, затем добавьте плагин в Playlist на полный экран. Используйте Force Refresh и запрос следующего экрана на устройстве.
5. Интервал обновления можно поставить 1 час. Смена дня рассчитывается по Москве, но экран меняется при следующем запросе устройства.

## Чёрно-белый фон с дизерингом

Для версии с точечными полутонами: Playlist → ⋯ у этого плагина → Presentation → Black & White (1-bit). Затем сохраните обновлённый Full и выполните Force Refresh.

Класс `image-dither` включён только для фонового изображения. Сервер TRMNL преобразует его под выбранную палитру; цифры остаются отдельным SVG-слоем. Это позволяет передавать полутона чёрно-белыми точками вместо сплошных серых областей. Точный рисунок точек зависит от алгоритма TRMNL и может отличаться от референса. Фактическую яркость нужно оценить на устройстве.

Локальный preview не выполняет серверный дизеринг. Документация: https://trmnl.com/framework/docs/3.3/image

## Изменение после ошибки размера

full.liquid занимает менее 2 KB. Фон загружается из artworks, Montserrat ExtraBold — из assets этого репозитория (копия официального шрифта). Встроенных Base64-ресурсов в production-шаблоне нет. Проверка размера <100 000 байт включена в build.py. Внешнюю загрузку шрифта и фона нужно проверить в TRMNL.

preview.html оставлен автономным: он содержит исходный арт и шрифт и не предназначен для вставки в TRMNL. Он не проверяет внешние ссылки и физический 2-bit рендер.

## Поведение

Логотип GTA VI: SVG поверх фона, без дополнительного серверного дизеринга. Позиция 56px слева / 48px сверху, ширина 210px. С учётом белого контура верхнее поле примерно 47px, как нижнее поле до тени числа 83; левый край оптически выровнен по цифрам. Положение счётчика не изменено. Цветной оригинал сохранён в `assets/gta-vi-logo-original.svg`; `build.py` создаёт монохромную версию. Внутри VI — встроенная точечная заливка Bayer с переменной плотностью; надпись и контуры остаются сплошными. Шаг точек рассчитан под ширину 210px.

Источник логотипа: https://upload.wikimedia.org/wikipedia/commons/d/d6/Grand_Theft_Auto_VI_logo_%28with_gradient%29.svg . Права на логотип принадлежат соответствующим правообладателям; лицензия шрифта на него не распространяется.

Montserrat ExtraBold 180px, белая заливка, наружная чёрная обводка 4px, тень вниз 10px. Фиксированы x=50 и базовая линия y=416. Дата выхода 19.11.2026 задана пользователем; расчёт по UTC+3, после выхода 0. Шесть проверок граничных дат пройдены в Python, выполнение Liquid проверяется в TRMNL.

Псевдослучайный выбор фона зависит от московского дня и длины списка. При неизменном списке фон остаётся тем же в течение дня. Повторы между днями допустимы. При одном арте смены нет.

`build.py` проверяет арифметику выбора для 0, 1, 2, 3, 4 и 10 артов: постоянство в течение дня, допустимые индексы и изменение выбора на протяжении 28 дней. Это проверка формулы в Python, не проверка рендера нескольких изображений на TRMNL. Для визуальной проверки новых артов временно оставьте по одному URL в Static Data и выполните Force Refresh; затем верните весь список.

## Права на материалы

Неофициальный фанатский проект, не связанный с Rockstar Games. Права на GTA VI и соответствующие иллюстрации принадлежат их правообладателям. Наличие арта в репозитории не предоставляет лицензию на его дальнейшее использование. Лицензия шрифта применяется только к шрифту.

Локальный `preview.html` генерируется через `build.py` и исключён из Git, чтобы не дублировать встроенные ресурсы.
